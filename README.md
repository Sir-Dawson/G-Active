# G-Active

Georgies personal training business.

This project is a static HTML landing page for G Active Fitness and is configured for Cloudflare Pages hosting.

## Deployment

Cloudflare Pages can deploy this repository directly from the root without a build step.

- Framework: static HTML
- Build command: not required
- Output directory: /
- Hosting: Cloudflare Pages

The site uses direct asset references and does not rely on GitHub Pages-specific behavior such as Jekyll processing or a .nojekyll workaround.
